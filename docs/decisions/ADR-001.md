# ADR-001: Visual Identity and Design System Architecture

## Status
Accepted

## Context
The application requirements mandate combining an artistic editorial aesthetic (inspired by Reference 1: warm ivory/cream backgrounds, forest green, burnt orange, hand-drawn illustrations, serif typography, literary notebook feel) with a modern educational dashboard (inspired by Reference 2: rounded information cards, clear statistics, progress charts, learning categories, and structured visual hierarchy).

The product is an offline-first Spanish learning application covering CEFR levels A1 to B2 using React Native, TypeScript, Expo, Supabase, and SQLite.

## Decision
1. **Design Tokens:**
   - Establish semantic design tokens in `src/theme/tokens.ts`, `src/theme/colors.ts`, `src/theme/typography.ts`, and `src/theme/spacing.ts`.
   - Palette: Warm Ivory (`#F6F0E7`), Soft Cream (`#FFF9F0`), Forest Green (`#153D32`), Deep Green (`#102E26`), Burnt Orange (`#F06423`), Soft Peach (`#F4B49B`), Ink Black (`#171715`), Muted Grey (`#858078`).
2. **Typography Pairing:**
   - Platform-safe editorial serif fonts (e.g. `Georgia`, `serif`) for headings and reading passages.
   - Clean, neutral sans-serif fonts for UI controls, metric values, and navigation labels.
   - Script/italic styling for warm handwritten annotations.
3. **Component Architecture:**
   - Modular components under `src/components/common`, `src/components/cards`, `src/components/charts`, `src/components/illustrations`, and `src/components/learning`.
   - SVG-based hand-drawn illustrations and icons to guarantee zero pixelation on all screen densities.
4. **Data Isolation:**
   - Keep UI components decoupled from storage by maintaining a clean repository pattern in `src/services/` and `src/data/`.
   - Maintain real progress tracking, FSRS spaced repetition, and real database/fixture content so all statistics reflect genuine user interaction.

## Consequences
- The application presents an unmistakable, premium, and calm aesthetic distinct from gamified or corporate apps.
- The design system is fully reusable and adaptable across screen sizes and platforms (iOS and Android).
- Zero compromise on technical requirements (React Native, TypeScript, Expo, SQLite, Supabase, JSON portability).
