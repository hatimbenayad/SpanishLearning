# NAVIGATION STRUCTURE

## Bottom Tab Navigation (Persistent)
1. **Inicio (`/home`):** Overview metrics, continue hero card, daily activity carousel, weekly bar chart, and skill proficiency breakdown.
2. **Aprender (`/learn`):** CEFR Level Selector (A1–B2) and direct category launchpads (Vocabulary, Grammar, Verbs, Reading, Listening, Exercises).
3. **Biblioteca (`/library`):** Curated Spanish literature & articles with tap-to-translate digital reader.
4. **Progreso (`/progress`):** Deep learning analytics, FSRS review forecasts, and CEFR milestone roadmap.
5. **Perfil (`/profile`):** User settings, JSON backup export/restore, and offline cache manager.

## Modal & Sub-Screen Stacks
- `/onboarding`: 4-step wizard with goal selection, level assessment, and daily pace commitment.
- `/vocabulary`: FSRS flashcard study mode and searchable word browser.
- `/grammar`: Structured rule cards, comparison tables, and inline exercises.
- `/verbs`: 6-tense conjugation tables and pronoun drills.
- `/reading`: Distraction-free reader with font size adjuster and translation popover.
- `/listening`: Dedicated player with speed selector and synced transcripts.
