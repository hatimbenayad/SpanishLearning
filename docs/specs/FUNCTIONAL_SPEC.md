# FUNCTIONAL SPECIFICATION

## 1. Scope & Modules
- **Onboarding Flow:** Welcoming 4-step wizard capturing user goals, self-assessed CEFR baseline, and daily time budget.
- **Home Dashboard:** Central hub aggregating study streaks, weekly performance charts, current recommended lesson, skill breakdown, and daily activity carousel.
- **Learn Hub:** Level-based navigator (A1–B2) organizing curriculum across Vocabulary, Grammar, Verbs, Reading, Listening, and Exercises.
- **Vocabulary Module:** FSRS spaced repetition review system, search bar, category filters, and favorite word curation.
- **Grammar Module:** Bite-sized rule cards, comparative syntax tables, common pitfalls, and inline practice questions.
- **Verb Conjugator:** Searchable database of regular (-ar, -er, -ir) and irregular verbs with complete 6-tense conjugation tables.
- **Reading Engine:** Digital reader with customizable typography, interactive tap-to-translate tokens, and comprehension quizzes.
- **Listening Engine:** Audio player with speed selector (0.75x–1.25x), scrub bar, and interactive synced transcripts.
- **Analytics & Progress:** Historical study time graphs, FSRS review queue forecasts, and CEFR milestone roadmap.
- **Profile & Settings:** Backup export to versioned JSON and restore mechanism with schema validation.
