# USER JOURNEYS

## Journey 1: Welcoming Onboarding & Personalization
1. **First Impression:** User opens the application and is greeted by an artistic editorial illustration of a student reading Spanish literature with warm coffee.
2. **Goal Selection:** User selects their prime motivation (e.g., Literature & Culture, Travel, Career).
3. **Level Calibration:** User picks their CEFR level (A1, A2, B1, or B2).
4. **Daily Commitment:** User chooses their study pace (10 min, 20 min recommended, or 30 min).
5. **Arrival:** User lands on the Dashboard with personalized greetings and immediate next steps.

## Journey 2: Daily Learning on the Dashboard
1. **Check-in:** User sees their streak (🔥 12 days), current level (A1), and total learning hours (7h 50m).
2. **One-Tap Action:** Prominent "Continue Your Journey" card presents Lesson 08 ("Pidiendo comida en el restaurante") with a clear progress meter.
3. **Exploration:** User taps "El café de la esquina" to read a short 4-minute cultural piece with instant word translations.

## Journey 3: Vocabulary Retention via FSRS Flashcards
1. **Daily Queue:** User navigates to Vocabulary module.
2. **Recall & Test:** User views the Spanish word, listens to pronunciation, and recalls meaning.
3. **Flipping:** User flips card to review English translation, definition, and authentic sentence context.
4. **Grading:** User taps Again (<10m), Hard (1d), Good (3d), or Easy (7d). The deterministic FSRS engine recalculates stability, difficulty, and sets the next review date.

## Journey 4: Reading with Interactive Word Translation
1. **Story Choice:** User selects a public domain reader (e.g., *El café de la esquina* or *Rinconete y Cortadillo*).
2. **Comfort Tuning:** User adjusts reading typography size (`A- / A+`).
3. **Instant Lookup:** User taps an unfamiliar word (`sobremesa`). A sleek popover opens with pronunciation, phonetic transcription, and cultural explanation.
4. **Word Collection:** User taps "Guardar en vocabulario", adding the word to their personal study deck.
